# TouchAnywhere

**在任何地方,用任何远程软件,都像用 iPad 随航一样触摸操作 Mac。**
单指滑动滚动、轻点点击、按住再动拖动、抓标题栏拖窗口,手感接近 iPad 在随航里控制 Mac,但走的是任意远程桌面软件,不限网络。

[English](README.md)

> 与苹果公司无关。macOS、Sidecar(随航)是苹果公司的商标。

## 我怎么用它

我的 Mac 放在家里。我用 **三星 Galaxy Z Fold**(展开,纯触屏)通过 **Jump Desktop** 控制它,Mac 上跑着 TouchAnywhere —— 在办公室、咖啡馆、国外都行。滑动就滚动,拖动就能挪窗口,点按能点中小按钮。我写网页代码、写文章、做日常工作都这样用。

在我自己的日常使用里,它给我的感觉比随航还顺手:不是随航的触摸不好,而是它哪儿都能用,而且我把细节一点点调到了不再碍事 —— 什么时候算滑动、什么时候算拖动,指尖偏了多远还算点中按钮。这是我个人的体验,不是评测数据,欢迎自己试。

## 要解决的痛点

随航让 iPad 能真正触摸控制 Mac,但只在 Mac 附近、同一局域网里能用。一出门,你只能靠远程桌面软件(Jump Desktop、向日葵/AweSun、RustDesk、VNC 等)连回去,触摸体验立刻变差:

- 手指传到 Mac 上只是**鼠标**。单指只能拖动,要滚动得用双指。
- 手指点窗口上十几个像素的小按钮,得点得非常准。
- 远程软件不知道你手指下面是什么,分不清"滚动这一页"还是"拖这个窗口"。

## 它做什么

一个装在**被控制的那台 Mac** 上的菜单栏小程序,盯着远程软件传来的鼠标事件并改写:

| 你的动作 | 结果 |
|---|---|
| 单指在内容上滑动 | 滚动,松手后带惯性 |
| 轻点 | 点击(连点两下 = 双击) |
| 点在小按钮**旁边** | 吸到最近的小控件(窗口按钮、工具栏图标、勾选框、标签页)并点它正中间 |
| 手指停 0.2 秒左右再动 | 真正的拖动,可选文字、拖东西 |
| 从标题栏、窗口顶部工具栏、滚动条、滑块、菜单、窗口边缘开始滑 | 保持普通拖动,所以能挪窗口、调大小 |
| 按着 ⌘ ⌥ ⌃ ⇧ | 不插手 |

默认不动本机鼠标和触控板(只翻译来自别的进程的输入)。

它不替代你的远程软件,而是让任何远程软件控制这台 Mac 时都像在用触屏设备。

- 其他软件(向日葵/AweSun、RustDesk、VNC 客户端等)只要以普通鼠标事件、从自己的进程注入输入,理论上能用,但**我没测过**,欢迎反馈。

## 安装

需要 Xcode 命令行工具里的 Swift 编译器(`xcode-select --install`)。不需要完整 Xcode,没有依赖,不联网。

```bash
git clone https://github.com/n486888108-hue/touch-anywhere-mac.git
cd touch-anywhere-mac
bash build.sh --install
```

然后在 **系统设置 → 隐私与安全性 → 辅助功能** 里允许 TouchAnywhere。开了就立刻生效,不用重启。菜单栏会出现一个小手图标。

以后重新编译,辅助功能权限不会丢(构建时用「只认程序编号」的签名)。如果开关亮着却没反应,在列表里用「−」删掉再用「+」加回来。

## 设置(点菜单栏小手图标)

- **翻译手指滑动**:总开关。
- **只翻译远程控制来的**:不动本机鼠标(默认开)。
- **松手后带惯性**、**方向反过来**。
- **滑动还是拖动**:手指停多久再动算拖动,0.15 / 0.22(默认)/ 0.35 秒。
- **点击吸附范围**:关 / 14 / 24(默认)/ 36 点。
- **诊断日志**:`~/Library/Logs/TouchAnywhere.log` 记录每次触摸下面是什么、为什么当成滑动或拖动。

## 原理

1. 用 `CGEventTap` 看左键按下、拖动、抬起。程序自己补发的事件带标记,不会重复处理。
2. 默认只处理「来源进程不是硬件」的事件(`eventSourceUnixProcessID != 0`),远程软件就是这样送输入的。
3. 手指落下时先把事件扣住,用辅助功能接口看下面是什么(`HitTest.swift`):标题栏/工具栏、滚动条、菜单、窗口边缘……
4. `TouchEngine.swift` 是一个纯状态机,只判断「滑动/点击/拖动/放行」并返回要补发的事件,不碰系统,所以可以单元测试。
5. 滚动以连续的像素滚轮事件补发,带开始/变化/结束阶段,并合成惯性。

全部是 Swift 和 AppKit,约 800 行。

## 自测

```bash
~/Applications/TouchAnywhere.app/Contents/MacOS/TouchAnywhere --selftest     # 判断规则,不碰系统
~/Applications/TouchAnywhere.app/Contents/MacOS/TouchAnywhere --scrolltest   # 弹小窗口,验证滚动方向
~/Applications/TouchAnywhere.app/Contents/MacOS/TouchAnywhere --snaptest     # 在真窗口的红黄绿按钮上验证点击吸附
~/Applications/TouchAnywhere.app/Contents/MacOS/TouchAnywhere --dragtest     # 模拟手指在标题栏拖动
~/Applications/TouchAnywhere.app/Contents/MacOS/TouchAnywhere --hit 600 500  # 这个点算不算可滑动
```

## 已知限制

- **多指手势看不见。** 远程软件会把它们压扁:我实测三指横滑传到 Mac 上只是普通横向滚动,没有任何手势事件。所以只在 Mac 这一端,做不了三指切桌面。
- 在内容里拖动(选文字、拖放)得先停一小会儿,这是让单指滑动变成滚动的代价。
- 判断落点用的是辅助功能接口,没及时回应的程序会被当成「可滑动」。
- 代码注释大多是中文,欢迎帮忙翻译。

## 想法

用屏幕边缘滑动或浮动条切桌面、捏合缩放(⌘ + 滚动)、按程序设置规则、签名公证的发布版。欢迎提 issue 和 PR。
